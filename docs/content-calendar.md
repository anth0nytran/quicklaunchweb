# QuickLaunchWeb Guide Content Calendar

Used by the scheduled guide-writing agent. Before writing, check this file and `lib/guides.ts` so no topic or main keyword repeats. Rotate themes so the same theme does not run twice in a row.

**Themes**
1. Facebook/Instagram ads for a specific Houston trade
2. Video (on-the-job contractor video, what to film, phone tips)
3. Shared leads vs. exclusive leads (Angi / HomeAdvisor / Thumbtack)
4. Speed to lead, follow-up, booking estimates, bigger jobs
5. Ad budgets and judging/hiring an agency
6. Houston-specific (seasons, suburbs, local buying habits)

**Rules carried over:** 3rd-grade reading level, direct answer first, question headings, at least one table, FAQ of 4-6, CTA "Book a Free Call" to `/#book`. No invented stats, clients, quotes or results. Never publish client lead counts, ad spend or cost per lead (`lib/adResults.ts` is private). Only use numbers from a named public source. Say "our team", never "call center". No guarantee. No prices.
